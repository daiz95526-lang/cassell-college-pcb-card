# Privacy and rights

The release is a separate copy of the local project. Its card identity is fictional: `RILEY MORGAN` and `CC-0001`. The EasyEDA project, SVG sources, Gerbers, and previews use this same identity.

Original reference images, actual-person identity, local project-path references, EDA account identifiers, old evidence screenshots, original manufacturing archives, and unreviewed reports were excluded. No API keys, tokens, passwords, cookies, or local login settings are included.

The artwork is an unofficial fan-made interpretation inspired by *Dragon Raja*. The source and license status of third-party reference material could not be established, so those reference images are not redistributed. No open-source license is asserted over the complete work; none is included in this repository. Third-party rights remain with their owners.
